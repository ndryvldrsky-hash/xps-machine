ТЕЛЕФОН A56 — ГОРЯЧИЕ КЛАВИШИ
================================================================

НАШИ, В ОКНЕ ТЕЛЕФОНА (работают, только когда окно A56 активно)
----------------------------------------------------------------
Ctrl +            элементы крупнее (плотность вверх, текст не меняется)
Ctrl -            элементы мельче
Ctrl Shift +      шрифт больше (только текст)
Ctrl Shift -      шрифт меньше
Ctrl 0            сброс: заводская плотность, шрифт 1.0, автоповорот
Ctrl R            повернуть в альбом / вернуть автоповорот
Ctrl W            пересоздать окно под текущую ориентацию
Ctrl M            развернуть окно на весь экран
Ctrl Shift M      вернуть обычный размер окна
Ctrl S            снимок экрана телефона -> буфер Windows и «Изображения\A56»
CapsLock          переключить язык НА ТЕЛЕФОНЕ (шлёт телефону Ctrl+Space)
Shift CapsLock    то же через adb — запасной способ

НАШИ, ГЛОБАЛЬНЫЕ (в любом окне Windows)
----------------------------------------------------------------
Ctrl Alt A        открыть окно телефона
Ctrl Alt S        снимок экрана телефона в буфер Windows
Ctrl Alt V        картинку из буфера Windows -> в галерею телефона
Ctrl Alt J / K    шрифт меньше / больше
Ctrl Alt N / M    элементы мельче / крупнее
Ctrl Alt 0        сброс размеров

ВСТРОЕННЫЕ В SCRCPY (модификатор — левый Alt)
----------------------------------------------------------------
Alt F             полноэкранный режим
Alt W             подогнать окно под кадр (только вручную)
Alt G             размер окна 1:1
Alt H             кнопка ДОМОЙ
Alt B             кнопка НАЗАД (то же — правая кнопка мыши)
Alt S             список приложений (то же — средняя кнопка мыши)
Alt M             кнопка МЕНЮ
Alt Стрелка вверх/вниз    громкость
Alt P             питание
Alt O             погасить экран телефона, трансляция продолжается
Alt Shift O       включить экран обратно
Alt N             раскрыть шторку уведомлений
Alt Shift N       свернуть шторку
Alt C             копировать выделенное на телефоне в буфер Windows
Alt V             вставить буфер Windows в телефон (ТЕКСТ, не картинки)
Alt Shift V       отправить буфер Windows на телефон
Alt Стрелка влево/вправо  повернуть КАРТИНКУ (телефон не трогает)
Alt I             счётчик кадров в секунду

МЫШЬЮ И ПЕРЕТАСКИВАНИЕМ
----------------------------------------------------------------
Правая кнопка     назад / включить экран
Средняя кнопка    список приложений
Колесо            прокрутка
Перетащить файл   скопировать файл на телефон (в /sdcard/Download)
Перетащить .apk   установить приложение

ЧТО ГДЕ ЛЕЖИТ
----------------------------------------------------------------
Скрипты и этот файл    W:\tools\scrcpy-win64-v3.1\
Горячие клавиши        a56_hotkeys.ahk (AutoHotkey, задача A56Hotkeys при входе)
Окно телефона          задача ScrcpyA56 / ярлык «Экран A56» на рабочем столе
Служебные ярлыки       папка «A56 настройки» на общем рабочем столе
Журнал запусков окна   A56.log рядом со скриптами
Снимки экрана          Изображения\A56
Картинки на телефон    /sdcard/Pictures/FromWindows (последние 30)

ЕСЛИ ЧТО-ТО НЕ РАБОТАЕТ
----------------------------------------------------------------
Окно не открывается    телефон мог уснуть: Wi-Fi и Tailscale отключаются
                       в глубоком сне — тронь экран телефона
Окно закрылось         смена плотности пересоздаёт дисплей Android;
                       окно поднимется само через несколько секунд
Картинка вертикальная  телефон на экране блокировки (локскрин всегда книжный)
                       либо нажми Ctrl W после поворота
После перезагрузки     порт 5555 слетает: подключи кабель и скажи Алёне,
телефона               она вернёт «adb tcpip 5555»
