# Присутствие на телефоне A56 — окно на XPS

Скрипты для scrcpy: живое окно телефона Samsung SM-A566B на XPS с управлением мышью
и клавиатурой. Заведено 2026-09-18. Термин «присутствие» — общий для всех устройств дома
(Коин, телефон, XPS, iMac): вижу экран → решаю → нажимаю.

## Куда ставить

Всё содержимое каталога — в `W:\tools\scrcpy-win64-v3.1\` рядом с `scrcpy.exe` и `adb.exe`
(системный диск XPS виден как `W:`, не `C:`). Сам scrcpy — сборка `scrcpy-win64-v3.1`
с github.com/Genymobile/scrcpy, AutoHotkey v2 — в `W:\tools\ahk\`.

Разовая настройка после распаковки:

    powershell -File make_shortcut.ps1    # ярлык «Экран A56» на рабочий стол
    powershell -File tidy_desktop.ps1     # служебные ярлыки — в папку «A56 настройки»
    powershell -File make_hotkeys.ps1     # ярлыки в меню «Пуск»
    powershell -File make_ahk_task.ps1    # задача A56Hotkeys: горячие клавиши при входе

Список горячих клавиш — `A56_hotkeys.txt`.

## Что важно знать

- **Окно запускается только задачей планировщика `ScrcpyA56`** под тем пользователем, который
  сидит за консолью. Из сессии WinRM (другая учётка) окно на экран не попадает, а scrcpy
  падает с `Could not create renderer`.
- **Связь идёт по сети**, не по кабелю: телефон переведён в `adb tcpip 5555`, адрес берётся
  из tailnet. Кабель нужен только чтобы вернуть этот режим после перезагрузки телефона.
- **Смена плотности экрана закрывает окно** — Android пересоздаёт дисплей. Скрипты размеров
  поднимают scrcpy обратно сами, напрямую, а не через планировщик.
- **Поворот телефона окно не переразмеряет**, а синтетический Alt+W (штатный «подогнать окно»)
  до SDL-окна scrcpy не доходит — поэтому `Ctrl+W` пересоздаёт окно.
- **Буферы обмена Windows и Android независимы.** Текст scrcpy синхронизирует сам, картинки —
  нет: `Ctrl+Alt+V` кладёт картинку из буфера Windows в галерею телефона файлом.
- **Кириллица через WinRM приезжает битой**, а `.ps1` без BOM PowerShell 5.1 читает как ANSI —
  все скрипты здесь в UTF-8 с BOM, `.bat` — с CRLF (с юниксовыми переводами строк cmd отвечает
  «The system cannot find the path specified»).
- `WScript.Shell` не сохраняет ярлык с кириллицей в имени — создаём ASCII-именем
  и переименовываем через `[IO.File]::Move`.

## Со стороны Home Assistant

Витрина «Телефон A56» на дашборде «май», датчик `sensor.telefon_a56`, кнопки через
`shell_command.a56_control`. Сборщик и управление — в основном репозитории `/config`:
`.local/bin/a56_status.py`, `.local/bin/a56_control.sh`. MCP-сервер для агента —
`/config/a56_mcp.py`.
